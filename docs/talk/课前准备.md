# 今天下午分享会 · 课前准备（15 分钟，现在做）

今天下午有一段，是**你自己动手做一个能玩的小游戏**。

场地的网撑不住三十个人同时装东西，所以**装的部分现在先做掉**，到场之后只用打字。
全程不用注册、不用充值、不用会写代码。

**你需要**：一台电脑（Windows / Mac 都行）＋ 能上网 ＋ 15 分钟。

> 通知得急，我知道。**装不完也照常来** —— 现场有兜底，两人一台照样能玩，不会让你干坐着。

---

## 第一步 · 装 Node.js（约 5 分钟）

打开 **nodejs.org**，下载 **LTS** 版本。

- Windows 选 **x64**
- Mac 如果是 M1 及以后的芯片，选 **ARM64**
- 一路点下一步就行，**安装选项里「加入 PATH」那个勾不要取消**

> 版本必须是 **22.19 以上**。直接下最新的 LTS 就对了，不用纠结。

---

## 第二步 · 装 dsh（约 2 分钟）

先打开终端：

- **Windows**：按 `Win + R`，输入 `终端`，回车
- **Mac**：聚焦搜索里搜「终端」，打开

然后把下面这行粘进去，回车，等它跑完（一两分钟，中间会刷一堆字，正常）：

```
npm i -g @deepseek-ai/dsh
```

---

## 第三步 · 让它跑起来，看一眼（约 3 分钟）

还在那个终端窗口里，敲：

```
dsh web
```

然后浏览器打开：**http://127.0.0.1:3080**
（多数电脑会自己弹出来）

**看到界面，这一步就算成功了。**

两个提醒：

- **别关那个终端窗口。** 关了网页就断——它不是装完就常驻的服务，下次要用再敲一次 `dsh web`。
- 它会问你要 **API Key**。**下午现场我发，你现在不用注册、也不用充值。**
  （如果我已经在群里发了 Key，就现在填上，随便打一句「你好」试试——能回话，就百分百没问题了。）

---

## 第四步 · 建一个空文件夹（10 秒）

随便哪个盘，新建一个**空文件夹**，比如 `D:\我的游戏`。

下午第一件事就是把它交给 dsh，所以**记住它在哪**。

---

## 装不上？大概率是这三个

**敲 `dsh` 说「不是命令 / command not found」**
→ 关掉终端窗口，**重新开一个**再敲。装完要重开窗口，路径才会刷新。

**提示 Node 版本过低**
→ 敲 `node -v` 看一眼。低于 22.19 就回 nodejs.org 重下 LTS 覆盖安装，装完记得重开终端。

**`npm i -g` 那一步刷红字**
→ 先原样再跑一遍，多数是网络抖。还不行就先跳过，带电脑来就行，现场两人一台，不影响你参加。
